> 🔴 **Be different. Be Open.**

M3gram is an **open-source Telegram client** redesigned with **Material 3** and its own visual identity.

<br>

## ✦ Features

|                        |                               |
| ---------------------- | ----------------------------- |
| 🎨 **Material 3**      | A complete modern UI          |
| 🖌️ **Customization**  | Themes, colors and appearance |
| 👤 **M3gram Profiles** | Your own profile layer        |
| 🏅 **Badges**          | Earn and show badges          |
| 🖼️ **Backgrounds**    | Personalize your profile      |
| 🔓 **Open Source**     | Built in the open             |

<br>

## ⚡ Install

Download the latest APK from **Releases**, install it and sign in with your Telegram account.

No separate M3gram account.

<br>

## 🔨 Build

```bash
git clone --recursive --shallow-submodules https://github.com/dtech-special/m3gram.git
cd m3gram
./gradlew assembleDebug
```

<br>

## 🧩 Based on

M3gram is based on the **Telegram Android** client and keeps Telegram's core functionality while introducing a different UI and M3gram-specific features.

<br>

## ⚠️ Disclaimer

M3gram is an independent project and is **not affiliated with Telegram**.
